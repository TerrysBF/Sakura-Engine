\doxysubsection{Detailed Description}
\doxylink{class_fbx_i_o}{Fbx\+IO} represents an FBX file. It is primarily used by FBX importers (\doxylink{class_fbx_importer}{Fbx\+Importer}) and exporter (\doxylink{class_fbx_exporter}{Fbx\+Exporter}) when reading or writing data from or to a disk or memory. Most users will not use the \doxylink{class_fbx_i_o}{Fbx\+IO} class directly but will use an instance of either \doxylink{class_fbx_importer}{Fbx\+Importer} or \doxylink{class_fbx_exporter}{Fbx\+Exporter} to read or write FBX files.

An FBX file may contain binary data or ASCII data. A good way to learn the internal structure of a FBX file is to open a FBX file saved in ASCII in a text editor.
