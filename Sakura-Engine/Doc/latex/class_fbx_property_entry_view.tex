\doxysubsection{Detailed Description}
\doxylink{class_fbx_property_entry_view}{Fbx\+Property\+Entry\+View} represents property entry in entry tables. The property can be used as source or destination for the binding entry. Use this class to manipulate binding table\textquotesingle{}s attributes.
