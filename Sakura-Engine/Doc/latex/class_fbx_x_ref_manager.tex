const char\texorpdfstring{$\ast$}{*} Fbx\+XRef\+Manager\+::s\+Embedded\+File\+Project\hspace{0.3cm}{\ttfamily [static]}}

This project is used for creating the "{}.\+fbm"{} folders that are used for storing embedded resources in FBX files.

When not set, or if the folder is not writable, the "{}.\+fbm"{} folder is created alongside the FBX file.

If we cannot write in that folder, we look at the s\+Temporary\+File\+Project location. If no folder is set in the s\+Temporary\+File\+Project location, or it is not writable, the operating system\textquotesingle{}s Temp folder becomes the location.
