\doxysubsection{Detailed Description}
The \doxylink{class_fbx_scene_renamer}{Fbx\+Scene\+Renamer} provides a way to easily rename objects in a scene without using the \doxylink{class_fbx_renaming_strategy}{Fbx\+Renaming\+Strategy} class. \doxylink{class_fbx_scene_renamer}{Fbx\+Scene\+Renamer} can remove name clashing and illegal characters. It also manages namespaces.

Example\+: Maya only accepts names with letters, digits, or underscores, and we want to convert all the names of a scene from FBX format to Maya format.
