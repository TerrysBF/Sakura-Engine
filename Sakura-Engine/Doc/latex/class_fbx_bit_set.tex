\doxysubsection{Detailed Description}
An automatic growing array of bit.

The bit array will automatically grow when specifying bit indexes that are greater than the array size when calling Set\+Bit or Unset\+Bit. Indexes can vary from 0 to FBXSDK\+\_\+\+UINT\+\_\+\+MAX-\/1. When an invalid index is returned from any functions, FBXSDK\+\_\+\+UINT\+\_\+\+MAX is returned. The bit array is not thread safe.
