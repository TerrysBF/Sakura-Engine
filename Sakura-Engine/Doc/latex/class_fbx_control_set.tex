\doxysubsection{Detailed Description}
This class contains all methods to either set-\/up an exported control rig or query information on an imported control rig. A Control rig is a character manipulation tool that lets you change the position and orientation of a character to create or alter animation.

This class also contains some methods to manipulate the \doxylink{class_fbx_effector}{Fbx\+Effector} and \doxylink{class_fbx_control_set_link}{Fbx\+Control\+Set\+Link}.

The \doxylink{class_fbx_control_set}{Fbx\+Control\+Set} class contains FK rig (Forward Kinematics) and IK rig (Inverse Kinematics) animation. The FK rig is represented by a list of nodes while the IK rig is represented by a list of effectors.

You can access the FK rig with the \doxylink{class_fbx_control_set_link}{Fbx\+Control\+Set\+Link} class, using the functions \doxylink{class_fbx_control_set_a448f77a06237db1189da806fb6d841f1}{Fbx\+Control\+Set\+::\+Set\+Control\+Set\+Link()} and \doxylink{class_fbx_control_set_aec762ddd33c928ef92493332ad5adcc8}{Fbx\+Control\+Set\+::\+Get\+Control\+Set\+Link()}.

You can access the IK rig with the \doxylink{class_fbx_effector}{Fbx\+Effector} class, using the functions \doxylink{class_fbx_control_set_aa274b9d69d66d7d00d7769683e275922}{Fbx\+Control\+Set\+::\+Set\+Effector()} and \doxylink{class_fbx_control_set_a9783b07eedcb540aff19bf6037070d5e}{Fbx\+Control\+Set\+::\+Get\+Effector()}.
