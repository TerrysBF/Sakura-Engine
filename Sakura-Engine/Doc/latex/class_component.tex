\doxysubsection{Detailed Description}
Clase base abstracta para todos los componentes del juego. 

La clase \doxylink{class_component}{Component} define la interfaz básica que todos los componentes deben implementar, permitiendo actualizar y renderizar el componente, así como obtener su tipo.
