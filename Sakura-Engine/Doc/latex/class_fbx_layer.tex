\doxysubsection{Detailed Description}
\doxylink{class_fbx_layer}{Fbx\+Layer} class provides a base for the layering mechanism.

A layer can contain one or more of the following layer elements\+: \begin{DoxyItemize}
\item Normals \item Binormals \item Tangents \item Materials \item Polygon Groups \item UVs \item Vertex Colors \item Smoothing informations \item Vertex Creases \item Edge Creases \item Custom User Data \item Visibilities \item Textures (diffuse, ambient, specular, etc.) (deprecated)\end{DoxyItemize}
A typical layer for a \doxylink{class_mesh}{Mesh} contains Normals, UVs and Materials. A typical layer for NURBS contains only Materials. In the case of the NURBS, the NURBS\textquotesingle{} parameterization is used for the UVs; no UVs should be specified.

In most cases, you only need a single layer to describe a geometry. Many applications only support what is defined on the first layer. Take this into account when you fill the layer. For example, it is legal to define the Layer 0 with the UVs and then define the model\textquotesingle{}s Normals on layer 1. However if you construct a file this way, it may not be imported correctly in other applications. Store the Normals in Layer 0 to avoid problems.

Since FBX SDK 2011, Textures are connected to the properties of \doxylink{class_fbx_surface_material}{Fbx\+Surface\+Material} derived classes. \doxylink{class_fbx_layer_element_texture}{Fbx\+Layer\+Element\+Texture} is no longer used. See the code example in \doxylink{class_fbx_layer_element_texture}{Fbx\+Layer\+Element\+Texture} for how to connect a texture.

Since FBX SDK 2011, texture layering is achieved by \doxylink{class_fbx_layered_texture}{Fbx\+Layered\+Texture}. See the code example in \doxylink{class_fbx_layered_texture}{Fbx\+Layered\+Texture} for how to blend textures.

Normally, you can access layer from \doxylink{class_fbx_layer_container}{Fbx\+Layer\+Container} like \doxylink{class_fbx_geometry}{Fbx\+Geometry}. For example,
