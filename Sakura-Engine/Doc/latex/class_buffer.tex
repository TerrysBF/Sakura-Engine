\doxysubsection{Detailed Description}
Encapsula un {\ttfamily ID3\+D11\+Buffer} para v{\ucr}rtices, {\ucr}ndices o constantes, incluyendo creaci{\ucr}n, actualizaci{\ucr}n y enlace. 

Esta clase administra la vida de un {\ucr}nico buffer de D3\+D11 y su uso en etapa de render. Soporta\+:
\begin{DoxyItemize}
\item Creaci{\ucr}n como Vertex/\+Index buffer a partir de un {\ttfamily \doxylink{class_mesh_component}{Mesh\+Component}}.
\item Creaci{\ucr}n como Constant buffer a partir de un tama{\ucr}o (Byte\+Width).
\item Actualizaci{\ucr}n de datos (p. ej. {\ttfamily Update\+Subresource}).
\item Enlace del buffer a la etapa correspondiente del pipeline.
\end{DoxyItemize}

\begin{DoxyNote}{Note}
