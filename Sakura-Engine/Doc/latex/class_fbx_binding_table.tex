\doxysubsection{Detailed Description}
A binding table represents a collection of bindings from source types such as \doxylink{class_fbx_object}{Fbx\+Object}, or Fbx\+Layer\+Elements to corresponding destinations, usually a third party shader parameters. Binding represents a link between internal object(e.\+g. \doxylink{class_fbx_object}{Fbx\+Object}) and external object(e.\+g. HLSL shader parameters).
