\doxysubsection{Detailed Description}
FBX SDK date\&time class. Property used to store date and time information; not related to a \doxylink{class_fbx_time}{Fbx\+Time}, which is used for film-\/related operations. The date and time property does not make any provisions for UTC, GMT or local zones; this is entirely up to client code to know what they are dealing with.
