\doxysubsection{Detailed Description}
A Character is a person or animal with pre-\/defined skeleton system. The skeleton system is composed of multiple named node (skeleton). This class contains all methods to setup an exported character or query information on an imported character. This class also contains some methods for manipulating the \doxylink{class_fbx_character_link}{Fbx\+Character\+Link}, \doxylink{class_fbx_control_set}{Fbx\+Control\+Set}

The most important part of a \doxylink{class_fbx_character}{Fbx\+Character} is the \doxylink{class_fbx_character_link}{Fbx\+Character\+Link}. There is one \doxylink{class_fbx_character_link}{Fbx\+Character\+Link} for each characterized node. For more information see \doxylink{class_fbx_character_link}{Fbx\+Character\+Link} class documentation.
