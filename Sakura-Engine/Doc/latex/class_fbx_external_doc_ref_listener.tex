\doxysubsection{Detailed Description}
Typical handler for the referenced document events.

Register it like so\+: \doxylink{class_fbx_external_doc_ref_listener}{Fbx\+External\+Doc\+Ref\+Listener} l\+Ref\+Doc\+Listener( sdk\+Manager, file\+Name ); \doxylink{class_fbx_event_handler}{Fbx\+Event\+Handler} \texorpdfstring{$\ast$}{*} l\+Handler = l\+Ref\+Doc\+Listener.\+Bind(scene,                                                \&\+Fbx\+External\+Doc\+Ref\+Listener\+::\+Handle\+Event); ~\newline


And later unregister it like so\+: l\+Ref\+Doc\+Listener.\+Unbind(l\+Handler);
