\doxysubsection{Detailed Description}
Matrix conversion filter.

\begin{DoxyRemark}{Remarks}
The current implementation of this filter expects to process 9 curves. If the Apply\+Unroll flag is enabled, set with a call to \doxylink{class_fbx_anim_curve_filter_matrix_converter_abcfe379526feec5a8d3ffc9e3e435d66}{Set\+Apply\+Unroll()}, the internal unroll filter will automatically be configured to convert USER and BREAK tangents to AUTO (refer to the \doxylink{class_fbx_anim_curve_filter_unroll}{Fbx\+Anim\+Curve\+Filter\+Unroll} documentation). 
\end{DoxyRemark}
