\doxysubsection{Detailed Description}
This class describes image mapping on top of geometry. \begin{DoxyNote}{Note}
To apply a texture to geometry, first connect the geometry to a \doxylink{class_fbx_surface_material}{Fbx\+Surface\+Material} object (e.\+g. \doxylink{class_fbx_surface_lambert}{Fbx\+Surface\+Lambert}) and then connect one of its properties (e.\+g. Diffuse) to the \doxylink{class_fbx_file_texture}{Fbx\+File\+Texture} object. 
\end{DoxyNote}
