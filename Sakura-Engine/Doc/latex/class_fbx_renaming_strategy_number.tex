\doxysubsection{Detailed Description}
Implements a renaming strategy that resolves name clashes by adding number postfixes. For example, when there are three objects with the same name "{}\+My\+Object"{}, they will be renamed to "{}\+My\+Object"{}, "{}\+My\+Object1"{} and "{}\+My\+Object2"{}.
