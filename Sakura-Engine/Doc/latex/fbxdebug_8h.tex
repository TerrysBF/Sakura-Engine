\doxysubsection{Detailed Description}
Debugging macros and functions.

All macros and functions are removed in release builds. To enable asserts, a debug build is required as well as the environment variable "{}\+FBXSDK\+\_\+\+ASSERT"{} set to 1 is also required. By default, assertions will pop-\/up a window. It is possible to disable the pop-\/up on the Windows platform by calling the following code\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\_CrtSetReportMode(\_CRT\_ASSERT,\ \_CRTDBG\_MODE\_DEBUG);}

\end{DoxyCode}
