\doxysubsection{Detailed Description}
This class represents the coordinate system of the scene and can convert scenes to other coordinate systems. By default the \doxylink{class_fbx_scene}{Fbx\+Scene} uses a Y-\/\+Up axis system. If the calling application wishes to change the default axis it will need to define the new axis system and call the convert method with the scene as argument. The appropriate transforms will be applied to the first level objects of the scene only (objects whose parent is the scene itself). Child objects do not need to be transformed since they inherit from their parents. The adjustment will affect the translation animation curves and the objects pivots values (the rotation transformation is applied as a pre-\/rotation transform therefore the rotation animation curves do not need to be transformed). Once converted, the scene will have its axis definition changed to the new system.

No conversion will take place if the scene current axis system is equal to the new one.

The \doxylink{class_fbx_axis_system_ad41a41f7ccd9167f54d09b65ad781d00}{EUp\+Vector} specifies which axis has the up and down direction in the system (typically this is the Y or Z axis). The sign of the \doxylink{class_fbx_axis_system_ad41a41f7ccd9167f54d09b65ad781d00}{EUp\+Vector} is applied to represent the direction (1 is up and -\/1 is down relative to the observer).

The \doxylink{class_fbx_axis_system_a34bce1daad7ed6ae71916bb825d3ec87}{EFront\+Vector} specifies which axis has the front and back direction in the system. It is not an independent variable, which means it depends on \doxylink{class_fbx_axis_system_ad41a41f7ccd9167f54d09b65ad781d00}{EUp\+Vector}. The enum values Parity\+Even and Parity\+Odd denote the first one and the second one of the remain two axes in addition to the up axis.

For example if the up axis is X, the remain two axes will be Y And Z, so the Parity\+Even is Y, and the Parity\+Odd is Z ; If the up axis is Y, the remain two axes will X And Z, so the Parity\+Even is X, and the Parity\+Odd is Z; If the up axis is Z, the remain two axes will X And Y, so the Parity\+Even is X, and the Parity\+Odd is Y.

There still needs a parameter to denote the direction of the \doxylink{class_fbx_axis_system_a34bce1daad7ed6ae71916bb825d3ec87}{EFront\+Vector} just as the \doxylink{class_fbx_axis_system_ad41a41f7ccd9167f54d09b65ad781d00}{EUp\+Vector}. And the sign of the \doxylink{class_fbx_axis_system_a34bce1daad7ed6ae71916bb825d3ec87}{EFront\+Vector} represents the direction (1 is front and -\/1 is back relative to observer).

If the front axis and the up axis are determined, the third axis will be automatically determined as the left one. The \doxylink{class_fbx_axis_system_a7cf0485846b560fa34f86932c02ec333}{ECoord\+System} enum is a parameter to determine the direction of the third axis just as the \doxylink{class_fbx_axis_system_ad41a41f7ccd9167f54d09b65ad781d00}{EUp\+Vector} sign. It determines if the axis system is right-\/handed or left-\/handed just as the enum values.

\Hypertarget{class_fbx_axis_system_a7adca2ea8d5934185b42f28cf9213314}\index{FbxAxisSystem@{FbxAxisSystem}!ParseAxisSystem@{ParseAxisSystem}}
\index{ParseAxisSystem@{ParseAxisSystem}!FbxAxisSystem@{FbxAxisSystem}}
\doxysubsubsection{\texorpdfstring{ParseAxisSystem()}{ParseAxisSystem()}}
{\footnotesize\ttfamily \label{class_fbx_axis_system_a7adca2ea8d5934185b42f28cf9213314} 
static bool Fbx\+Axis\+System\+::\+Parse\+Axis\+System (\begin{DoxyParamCaption}\item[{const char \texorpdfstring{$\ast$}{*}}]{p\+Axes}{, }\item[{\mbox{\hyperlink{class_fbx_axis_system}{Fbx\+Axis\+System}} \&}]{p\+Output}{}\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [static]}}

Static method.

This function takes a string representation of the axis system. It parses the string and outputs by reference. If the parse fails, the output is unmodified and the function returns false.

The representation is three letters long, case-\/sensitive.

The first letter is the left-\/right axis, x, y or z. Lower-\/case means the axis is positive going to the right, upper-\/case means it is positive going left.

The second letter is the vertical axis, x, y or z. Lower-\/case means the axis is positive going to up, upper-\/case means it is positive going down.

The third letter is the forward axis, x, y or z. Lower-\/case means the axis is positive going into the screen, upper-\/case means it is positive going from the screen, towards the viewer.

Example\+: Maya Y-\/up is "{}xy\+Z"{} -- x points right, y points up, z points out of the screen. Example\+: Max is "{}xzy"{} -- x points right, z points up, y points into the screen.

Note\+: It is possible to represent the same axis system in different ways with the same letters. For example, Maya Y-\/up can also be "{}\+Xyz"{} if turned 180 degrees.
