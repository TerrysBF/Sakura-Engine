\doxysubsection{Detailed Description}
This class defines some utility functions to access \doxylink{class_fbx_surface_material}{Fbx\+Surface\+Material} properties by name regardless of the actual material definition. These functions are provided for convenience to simplify the manipulation of Materials (especially shader definitions that use the \doxylink{class_fbx_implementation}{Fbx\+Implementation} and the \doxylink{class_fbx_binding_table}{Fbx\+Binding\+Table} which defines a variable number of properties).

\begin{DoxyRemark}{Remarks}
For a complete access to the \doxylink{class_fbx_surface_material}{Fbx\+Surface\+Material} objects, it may still be required to directly access the data using the relevant objects.
\end{DoxyRemark}
