\doxysubsection{Detailed Description}
The base class to inherit from when creating new plug-\/ins for the FBX SDK. Plug-\/ins for the FBX SDK are extremely flexible allowing a wide-\/range of possibilities. For example, one can write his own plug-\/in to add new readers/writers to the current list of supported I/O formats, or add new dynamic classes to instantiate custom objects that can later be stored in FBX files. We also use the same interface for plug-\/ins written using the FBX Extension SDK, which allow additional callbacks for other various Autodesk products enabling greater interoperability with multiple various SDKs.
