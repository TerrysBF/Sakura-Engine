\doxysubsection{Detailed Description}
This class provides the functionality to convert geometry nodes attributes (\doxylink{class_fbx_mesh}{Fbx\+Mesh}, \doxylink{class_fbx_nurbs}{Fbx\+Nurbs} and \doxylink{class_fbx_patch}{Fbx\+Patch}) and mainly focuses on the two major categories\+: Triangulation and conversion between NURBS and Patches surfaces.

 ~\newline
 a) mesh vertex;~\newline
 b) mesh polygon;~\newline
 c) mesh edge;~\newline
 d) mesh elements; only the layer 0 elements are merged with some restrictions.~\newline
 e) if there are skins for old mesh, merge these skins. The new skin clusters link to old skeletons.~\newline
~\newline

\end{DoxyReturn}
\begin{DoxyRemark}{Remarks}
This method creates a new mesh, leaving the source mesh unchanged.~\newline
 The transform of new mesh node is\+: translate (0, 0, 0), rotation (0, 0, 0), scale (1, 1, 1).~\newline
 For layer element material, normal, smoothing, UV set, vertex color, binormal, tangent and polygon group, if any mesh misses these element, the merge for this kind of element is skipped.~\newline
 For layer element crease, hole, visibility, if any mesh has such element, the kind of element will be merged. The missing element will be filled with default values.~\newline
 For meshes with skin binding, if the pose of frame 0 is different with bind pose, the new mesh will be distorted.~\newline
