\doxysubsection{Detailed Description}
This class contains functions for accessing global light settings.

\begin{DoxyRemark}{Remarks}
This class exists for FBX version 6.\+x and earlier. The new FBX v7.\+x file format that is now the default no longer uses it. The relevant data (a subset of this class) has been moved to the \doxylink{class_fbx_global_settings}{Fbx\+Global\+Settings} object and should be used instead. 
\end{DoxyRemark}
