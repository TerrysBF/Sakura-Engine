\doxysubsection{Detailed Description}
The base class of geometric objects that support control point deformations (e.\+g. \doxylink{class_fbx_mesh}{Fbx\+Mesh}, \doxylink{class_fbx_nurbs}{Fbx\+Nurbs}, and \doxylink{class_fbx_patch}{Fbx\+Patch}). The \doxylink{class_fbx_geometry}{Fbx\+Geometry} provides support for the following kinds of deformations.

\begin{DoxyItemize}
\item Skin deformation deformers \item Vertex cache deformers \item Geometry weighted maps \item Shapes\end{DoxyItemize}
Most of the methods of \doxylink{class_fbx_geometry}{Fbx\+Geometry} are wrappers to simplify the access/manipulation of the connections to the deformers. For example, calling the \doxylink{class_fbx_geometry_a8cca6f160b52ee1ffd799c599c36f784}{Get\+Deformer\+Count()} method is the same thing as calling\+:
