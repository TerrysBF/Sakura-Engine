\doxysubsection{Detailed Description}
This base class is an abstract implementation of a renaming strategy for avoiding name clashes. An implementation of a reader (\doxylink{class_fbx_reader}{Fbx\+Reader}) or writer (\doxylink{class_fbx_writer}{Fbx\+Writer}) class must call a concrete implementation of "{}\+Fbx\+Renaming\+Strategy\+Interface\+::\+Rename()"{} every time a name is imported or exported to avoid name clashes. Any class deriving from \doxylink{class_fbx_renaming_strategy_interface}{Fbx\+Renaming\+Strategy\+Interface} must implement \doxylink{class_fbx_renaming_strategy_interface_a2090b5ae43936b617ec5d75015923f69}{Fbx\+Renaming\+Strategy\+Interface\+::\+Clear()}, \doxylink{class_fbx_renaming_strategy_interface_a1b91016c68dd9c7031624026fd39638a}{Fbx\+Renaming\+Strategy\+Interface\+::\+Rename()}, and \doxylink{class_fbx_renaming_strategy_interface_af21b40aff16d65816a6c361cf7b6fdba}{Fbx\+Renaming\+Strategy\+Interface\+::\+Clone()}.
