\doxysubsection{Detailed Description}
Layer element for mapping materials (\doxylink{class_fbx_surface_material}{Fbx\+Surface\+Material}) to a geometry.

FBX SDK 2011 and later connects materials (\doxylink{class_fbx_surface_material}{Fbx\+Surface\+Material}) to nodes (\doxylink{class_fbx_node}{Fbx\+Node}). The direct array of this class is no longer used. The integer "{}n"{} in the index array of this class represents the n-\/th material (zero-\/based) connected to the node.

For example\+:

Mapping mode e\+All\+Same and index array \{0\} means the whole geometry is assigned with the 0-\/th material connected to the node.

Mapping mode e\+By\+Polygon and index array \{0, 1\} means the first polygon is assigned with the 0-\/th material and the second polygon is assigned with the 1-\/th material.

You can access the materials from a node by using \doxylink{class_fbx_node_a00fabc04c839f665fa5d4a0b49859745}{Fbx\+Node\+::\+Get\+Material\+Count()} and Fbx\+Node\+::\+Get\+Material(int p\+Index) or the more generic calls to Get\+Src\+Object\+Count$<$\+Fbx\+Surface\+Material$>$() and Get\+Src\+Object$<$\+Fbx\+Surface\+Material$>$(index)

\begin{DoxyRemark}{Remarks}
