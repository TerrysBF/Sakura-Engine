\doxysubsection{Detailed Description}
This class facilitates the testing/reporting of errors. It encapsulates the status code and the internal FBXSDK error code as returned by the API functions. By default, the class will not accumulate all the error messages into the history array. If this history is desired, the object must be configured by calling Keep\+Error\+String\+History(true)
