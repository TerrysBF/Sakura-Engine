\doxysubsection{Detailed Description}
A shape describes the deformation on a set of control points, which is similar to the cluster deformer in Maya. For example, we can add a shape to a created geometry. And the shape and the geometry have the same topological information but different position of the control points. With varying amounts of influence, the geometry performs a deformation effect.

Shape can be represented in 2 ways\+: \begin{DoxyItemize}
\item Legacy style (default)\+: in legacy style only control point positions and normals are handled. In this style the control point position value and normal are saved as relative values to the base geometry values. Only normals for which the control point position has changed will be exported. \item Modern style(non Legacy style)\+: in this style the Layer\+Elements (\doxylink{class_fbx_layer_element}{Fbx\+Layer\+Element}) for Normal (\doxylink{class_fbx_geometry_base_a6d65f2458c553fd1ba6e2ef991f03797}{Fbx\+Geometry\+Base\+::\+Get\+Element\+Normal}), Tangent (\doxylink{class_fbx_geometry_base_ac62d2d4df0cb20c454f9e1e17f7a0447}{Fbx\+Geometry\+Base\+::\+Get\+Element\+Tangent}) , Bi\+Normal (Fbx\+Geometry\+Base\+::\+Get\+Element\+Bi\+Normal), Vertex\+Color (\doxylink{class_fbx_geometry_base_ad042469624e0834537343f8ea4d981fc}{Fbx\+Geometry\+Base\+::\+Get\+Element\+Vertex\+Color}) and UV (\doxylink{class_fbx_geometry_base_a89f8b5a9cd4e932a12ed9a5b4ced0379}{Fbx\+Geometry\+Base\+::\+Get\+Element\+UV}) will be exported if they have a corresponding \doxylink{class_fbx_layer_element}{Fbx\+Layer\+Element} on the base geometry of the \doxylink{class_fbx_blend_shape}{Fbx\+Blend\+Shape} (\doxylink{class_fbx_shape_aef5f2b99f712d1f417c1bb8d67a507f1}{Fbx\+Shape\+::\+Get\+Base\+Geometry}). The values will be exported only if they are different than values on the base geometry and no longer requires that the corresponding control point position has changed. In Modern style you can choose whether the values should be saved as absolute or relative values (\doxylink{class_fbx_shape_a3c43d0beb4b09756dc4f3c809e074f30}{Fbx\+Shape\+::\+Set\+Absolute\+Mode}).\end{DoxyItemize}
