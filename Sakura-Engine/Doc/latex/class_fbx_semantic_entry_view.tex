\doxysubsection{Detailed Description}
\doxylink{class_fbx_semantic_entry_view}{Fbx\+Semantic\+Entry\+View} stores a binding corresponding to a semantic within a shader file. A shader semantic is a parameter, a constant or an operator. So a shader semantic could bind with \doxylink{class_fbx_property}{Fbx\+Property} ( parameter, constant) and \doxylink{class_fbx_binding_operator}{Fbx\+Binding\+Operator} (operator).
