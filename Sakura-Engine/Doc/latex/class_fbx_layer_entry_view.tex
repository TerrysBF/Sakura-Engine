\doxysubsection{Detailed Description}
\doxylink{class_fbx_layer_entry_view}{Fbx\+Layer\+Entry\+View} encodes a layer element representation (the index of the layer, the type of the layer element and whether the layer element is a UVSet layer element) to a string stored in \doxylink{class_fbx_binding_table_entry}{Fbx\+Binding\+Table\+Entry} and decodes the string back to a layer element representation. This class is used in combination with \doxylink{class_fbx_binding_table_entry}{Fbx\+Binding\+Table\+Entry} to represent a source or a destination \doxylink{class_fbx_layer_element}{Fbx\+Layer\+Element}. \begin{DoxySeeAlso}{See also}
\doxylink{class_fbx_binding_table_entry}{Fbx\+Binding\+Table\+Entry} and \doxylink{class_fbx_binding_table}{Fbx\+Binding\+Table}. 
\end{DoxySeeAlso}
