\doxysubsection{Detailed Description}
Basic types definition.

Standard basic types used across the FBX SDK. There is also platform independent definitions that guarantee size across operating systems. The FBXSDK\+\_\+\+SYSTEM\+\_\+\+IS\+\_\+\+LP64 define is set to 1 when the operating system defines the "{}long"{} C++ type as 64-\/bit.
