int Fbx\+Character\+Link\+::m\+Rot\+Order}



Get the Post\+Rotation of this character link. 

Get the rotation order of this character link. Note that, for legacy reasons, this member stores the old rotation order values which still have some enum items that have been deprecated in the FBX SDK. For this reason, it is strongly suggested to use the {\itshape From\+Fbx\+EOrder()} and {\itshape To\+Fbx\+EOrder()} functions to ensure that the Fbx\+Euler\+::\+EOrder enum values are always used when querying or setting this property regardless of how it is internally stored.
