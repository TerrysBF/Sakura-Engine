\doxysubsection{Detailed Description}
Representa los elementos visibles que se van a renderizar en un frame. 

Esta clase sirve como una estructura temporal que organiza los objetos antes de enviarlos al renderer. Separa los objetos por tipo y guarda información como luces y skybox.
