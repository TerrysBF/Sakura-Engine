\doxysubsection{Detailed Description}
Base class of other writers used internally. This class provides the interfaces for writing files.

The role of the writer is to effectively "{}write"{} specific file data vs the role of the exporter is to select a specific writer and launch the writing of a file through that writer. \begin{DoxySeeAlso}{See also}
\doxylink{class_fbx_exporter}{Fbx\+Exporter}
\end{DoxySeeAlso}
ex\+:
\begin{DoxyItemize}
\item \doxylink{class_fbx_writer_fbx5}{Fbx\+Writer\+Fbx5} can write FBX 5 format files
\item \doxylink{class_fbx_writer_fbx6}{Fbx\+Writer\+Fbx6} can write FBX 6 format files
\item \doxylink{class_fbx_writer_fbx7}{Fbx\+Writer\+Fbx7} can write FBX 7 format files
\item \doxylink{class_fbx_writer_collada}{Fbx\+Writer\+Collada} can write Collada files
\item Fbx\+Writer\+Dxf can write Dxf files
\item ... etc.
\end{DoxyItemize}

A SDK user should -\/ normally -\/ not use this class, except if a custom writer must be created for plug-\/in extension, then \doxylink{class_fbx_writer}{Fbx\+Writer} must be the base class for the new custom writer in that particular situation.
