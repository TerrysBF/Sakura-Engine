Clase \doxylink{class_e_u_1_1_t_static_ptr}{TStatic\+Ptr} para manejo de un puntero estático. 

La clase \doxylink{class_e_u_1_1_t_static_ptr}{TStatic\+Ptr} gestiona un único objeto estático y proporciona métodos para acceder al objeto, verificar si el puntero es nulo y realizar operaciones básicas de manejo de memoria.
