\doxysubsection{Detailed Description}
Administra la jerarquia de entidades y su actualizacion espacial. 

El {\ttfamily \doxylink{class_scene_graph}{Scene\+Graph}} registra entidades, resuelve relaciones padre-\/hijo y actualiza las matrices de mundo antes de generar la informacion necesaria para render.
