\doxysubsection{Detailed Description}
Callback to operate on the embedded data while it is processed.

By default, the \doxylink{class_fbx_exporter}{Fbx\+Exporter} read the data to be embedded from a file on disk and the \doxylink{class_fbx_importer}{Fbx\+Importer} will extract the embedded data in the FBX file to a file on disk. Passing a properly initialized instance of this object to the \doxylink{class_fbx_importer}{Fbx\+Importer} and/or \doxylink{class_fbx_exporter}{Fbx\+Exporter} allows you to overwrite how the FBX SDK will access the embedded data if, for some reason, you do not want to use this default behaviour.
