\doxysubsection{Detailed Description}
A binding table entry stores a binding between a source and a destination. Users should not instantiate this class directly, but always call \doxylink{class_fbx_binding_table_base_af72e06246928352826d0ee59d11c7559}{Fbx\+Binding\+Table\+Base\+::\+Add\+New\+Entry()} to create a new entry in the binding table.
