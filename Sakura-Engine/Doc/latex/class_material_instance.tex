\doxysubsection{Detailed Description}
Representa una instancia concreta de un material. 

Esta clase permite usar un mismo material base, pero con diferentes texturas y parámetros para cada objeto en la escena. Es útil para no duplicar materiales y solo cambiar sus propiedades.
