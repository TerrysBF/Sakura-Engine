\doxysubsection{Detailed Description}
Class to encapsulate time units.

\doxylink{class_fbx_time}{Fbx\+Time} can measure time in hour, minute, second, frame, field, residual and also combination of these units. It is recommended to use \doxylink{class_fbx_time}{Fbx\+Time} for all time related operations. For example, currently it is used in \doxylink{class_fbx_global_settings}{Fbx\+Global\+Settings}, Fbx\+Global\+Time\+Settings, \doxylink{class_fbx_cache}{Fbx\+Cache}, all curve filters and all animation-\/related classes, etc. \doxylink{class_fbx_time}{Fbx\+Time} is just used to represent a moment, to represent a period of time, \doxylink{class_fbx_time_span}{Fbx\+Time\+Span} should be used. \begin{DoxySeeAlso}{See also}
\doxylink{class_fbx_time_span}{Fbx\+Time\+Span} 
\end{DoxySeeAlso}

Time modes. \begin{DoxyRemark}{Remarks}
\doxylink{class_fbx_time_acc529b00a0e8d4c3da3702449ca93031}{EMode} {\ttfamily e\+NTSCDrop\+Frame} is used for broadcasting operations where clock time must be (almost) in sync with time code. To bring back color NTSC time code with clock time, this mode drops 2 frames per minute except for every 10 minutes (00, 10, 20, 30, 40, 50). 108 frames are dropped per hour. Over 24 hours the error is 2 frames and 1/4 of a frame. A time-\/code of 01\+:00\+:03\+:18 equals a clock time of 01\+:00\+:00\+:00
\end{DoxyRemark}
\begin{DoxyParagraph}{}
\doxylink{class_fbx_time_acc529b00a0e8d4c3da3702449ca93031}{EMode} {\ttfamily e\+NTSCFull\+Frame} represents a time address and therefore is NOT IN SYNC with clock time. A time code of 01\+:00\+:00\+:00 equals a clock time of 01\+:00\+:03\+:18.
\end{DoxyParagraph}
