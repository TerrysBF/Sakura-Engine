Detailed Description

Renderer basado en Deferred Rendering.

Esta clase se encarga de renderizar la escena utilizando un G-Buffer para almacenar información de los objetos antes de aplicar la iluminación.

También administra sombras, objetos transparentes, skybox y diferentes vistas de depuración.
